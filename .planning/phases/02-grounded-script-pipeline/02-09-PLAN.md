<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSH tunnel → ndc-review | Only the operator should reach it; anything on the host loopback can too |
| Browser → POST handlers | Form input, cross-site requests, DNS rebinding |
| ndc-review container → host | Must not hold secrets or serve files (2026-10-21 lesson) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-21 | Information disclosure | Path traversal / arbitrary file read (the 2026-10-21 vector) | mitigate | 4-route regex table, no static handler, no file opens from input; tests for /proc/self/environ, %2e%2e |
| T-02-22 | Information disclosure | Secrets in the web container | mitigate | no env_file, no keys; DB + config only; test asserts env has no ANTHROPIC |
| T-02-23 | Spoofing | Internet exposure | mitigate | publish 127.0.0.1:8090 only; acceptance checks public IP refuses |
| T-02-24 | Tampering | CSRF / DNS rebinding through the tunnel | mitigate | Host allow-list, HMAC nonce bound to sha, CSP form-action 'self' |
| T-02-25 | Tampering | Approving a stale or unverified version | mitigate | review.store gate-in-transaction; 409 on stale |
| T-02-26 | Elevation | Container breakout surface | mitigate | read_only rootfs, cap_drop ALL, no-new-privileges, 256 MB / 0.25 CPU |
| T-02-27 | Information disclosure | Error pages leak internals | mitigate | fixed German error copy, no tracebacks, minimal access log |
</threat_model>
