<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM responses → DB | Model output becomes script versions |
| config/prompts → model | Prompt changes alter outputs |
| process → artifacts dir | Artifacts may be backed up/shared |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02 | Spoofing | Model invents a citation or quote | mitigate | custom-content block indices only; cited_text must equal stored sentence; mismatch aborts |
| T-02-03 | Information disclosure | API key in artifacts/cassettes/logs | mitigate | artifacts hold request body only; VCR filters x-api-key; acceptance grep |
| T-02-04 | Repudiation | "Which prompt produced this?" | mitigate | prompt_sha256 + request artifact per llm_run |
| T-02-05 | Tampering | Truncated/refused output stored | mitigate | stop_reason guard raises before any insert |
| T-02-06 | Elevation (content) | Medication/diagnosis content from sources | mitigate | prompt rule + claim-level check() (blocked → unapprovable, enforced by plan 04 gate) |
</threat_model>
