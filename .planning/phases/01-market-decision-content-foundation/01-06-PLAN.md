## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Scraped captions, transcripts, on-screen text → executor judgment | Untrusted third-party content is read by the in-session Claude executor (prompt injection) |
| Judgment JSON → DB / decision inputs | Judgments influence N_DE / S_DE and therefore the language decision |
| Downloaded media → host | Third-party video files on the shared host; CPU-heavy transcription |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-SC | Tampering | faster-whisper / av / pillow / numpy install + HF model download | mitigate | Task 1 blocking-human checkpoint; pinned in uv.lock; model from the official Systran repo into the project volume |
| T-06-01 | Tampering | Prompt injection via scraped text read by the executor | mitigate | Rubric declares all bundle content untrusted; bundles contain data only; output is a strict pydantic schema (extra keys forbidden); evidence substring guard; on-screen and decision-relevant judgments routed to the operator queue |
| T-06-02 | Tampering | Hallucinated citations inflating N_DE | mitigate | Non-substring evidence -> level 0 + queue; operator value wins; decision-relevant accounts always queued |
| T-06-03 | Information disclosure | API key | mitigate | No API calls and no anthropic dependency in Phase 1 (grep gate, D-21) |
| T-06-04 | Denial of service | Whisper starving the shared host | mitigate | ndc-heavy mem_limit 3g, cpus 1.0, nice 19, cpu_threads 1, small int8 model, quiet-hours guard |
