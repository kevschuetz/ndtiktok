<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public web (TikTok, YouTube, discovery sites) → scanner | Untrusted HTML/JSON and free text (bios, descriptions, comments) enter the DB |
| Scanner → platforms | Our request behaviour affects ToS compliance and IP reputation |
| Scanner → shared host | CPU/RAM/network use alongside polymarkt-watch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Shell/command injection via handles | mitigate | yt-dlp Python API only (grep gate: no subprocess/os.system); handle regex validation before any URL is built |
| T-04-02 | Tampering | Malicious/oversized scraped text | mitigate | Parameterized SQL; descriptions stored as data only, never evaluated; response size capped (httpx max 5 MB read) |
